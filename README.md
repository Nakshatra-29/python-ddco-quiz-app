# DDCO Python Quiz Application 🎯

An interactive, command-line quiz application built with Python to test and revise core concepts of **Digital Design and Computer Organization (DDCO)**.

## 🚀 Features
- Multiple-choice questions on Logic Gates, Flip-Flops, K-Maps, and Architecture.
- Real-time score tracking.
- Instant answer validation and feedback.
- Clean and interactive terminal interface.

## 🛠️ Built With
- **Language:** Python 3
- **Concepts Used:** Dictionaries, Lists, Functions, Loops, User Input Handling
